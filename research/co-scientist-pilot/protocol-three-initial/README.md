# 초기 가설 3개 프로필

사용자가 2026-10-08에 선택한 구성이다. GPT·Grok·GLM 5.3 Flash가 초기 가설을 하나씩 작성한다. Opus는 생성과 심사에서 제외한다.

- 초기: 가설 3개, 작성자를 제외한 두 모델이 각각 평가한다.
- 선택: 가설 2개를 생존시킨다. 작성 모델 2개를 강제하는 규칙은 아니다.
- 다음 세대: 생존 가설 2개 + 최고 가설의 변이 1개 + 두 생존 가설의 교차 1개, 총 4개다.
- 변이는 최고 가설의 작성자가 맡는다. 교차는 부모를 작성하지 않은 모델이 맡는다.
- 생존 가설의 점수는 유지하고 새 가설만 두 모델이 평가한다. 초기 이후 3세대를 반복한다.
- 총 새 가설 9개, 심사 18회, 정상 생성·심사 호출 합계 27회다. 기본 호출 상한 40회와 제한된 형식 재시도는 그대로다.
- 단독 비교도 초기 가설 3개를 사용하고, 이후 생존자 각각의 변이를 하나씩 만든다. 같은 모델의 별도 두 호출이 자기비판한다.

초기 개수 `initial_population=3`, 이후 정원 `population_limit=4`, 생존자 `survivor_count=2`를 분리했다. 나머지 문헌·프롬프트·평가 가중치·시간 상한은 `protocol-relaxed` 0.4를 복사했다. 기존 프로필과 과거 실행 결과는 보존한다.

실행 계획만 확인하려면 저장소 루트에서 다음 명령을 사용한다. 외부 모델은 호출하지 않는다.

```bash
python scripts/run_co_scientist_pilot.py --three-initial
```

실제 재시험을 시작하는 별도 명령은 다음과 같다. ALS·AML의 다중 및 단독 3개, 총 8개 실행과 DeepSeek 사후 평가를 새 출력 폴더에 기록한다.

```bash
python scripts/run_co_scientist_pilot.py --three-initial --run --out runs/co-scientist-three-initial-2026-10-08
```

이 변경을 확인할 때는 모의 모델 검증만 수행했으며 실제 모델 재시험은 시작하지 않았다. jev 사후 검사는 위 실행 명령에 자동 포함되지 않는다. 기존 `.env` 기반 사후 검사와 별도 단계다.
