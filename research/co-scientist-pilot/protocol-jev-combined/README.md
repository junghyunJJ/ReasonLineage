# jev 타입 조합 프로필 0.7

Noul 가설 성립·Choice 우선 수정 대상·4개 Score 구조 충실도를 조건부로 조합한다. 개발 예시48개와 별도 표현48개의 실제 jev 검증 후 이 프로필의 `j1.enforce=true`를 활성화했다. 기본 프로필과 기존 `--jev` 실행은 유지한다.

## 재작성 규칙

- 가설 존재 `P(yes)<0.5`: 같은 작성자에게 전체 가설을 한 번 다시 쓰도록 요청한다.
- 가설이 있으면 각 Score의 `P(2)+P(3)`가0.5 미만인 요소를 부족하다고 판단한다.
- Choice의 우선 대상이 부족한 요소와 일치하면 그 요소를 먼저, 다른 부족한 요소도 함께 한 번에 보완한다.
- Choice가 ‘결함 없음’이고 부족한 Score가 없으면 통과한다.
- Choice·Score가 불일치하면 본문 기준으로 jev를 한 번 재확인한다. 계속 불일치하면 `needs_review`를 기록하며 자동 재작성을 요청하지 않는다.
- 수정본을 검사하되 두 번째 재작성은 하지 않는다. 잔여 결함·미해결·검사 오류는 기록 후 후속 채점할 수 있으며 J1 완료 상태에 반영된다.

Score 요소는 기전, 근거와 추측의 구분, 대안을 구분하는 검증 전략, 반증 관찰이다. 0.5 등호는 통과한다. 확률들을 곱하거나 평균해 하나의 성공 확률로 표현하지 않는다. 문헌의 사실성·과학적 신규성·실험 성공을 판정하는 규칙은 아니다.

## 실행 구성

GPT·Grok·GLM-5.3-Flash, 초기3개·생존 가설2개·후속 변이1개+교차1개를 유지한다. 작성자를 제외한 두 모델이 비판·채점한다. jev는 fitness/생존자 선택에 관여하지 않으며 J2는 기록용이다. DeepSeek·Opus·Laya는 구성에 없다.

먼저 계획만 확인한다. 기본 동작은 실제 호출과 실행 폴더를 만들지 않는 dry run이다.

```bash
python scripts/run_co_scientist_pilot.py --jev-combined
```

별도 본실험을 실행할 때는 새 출력 폴더를 지정한다.

```bash
python scripts/run_co_scientist_pilot.py --jev-combined --run --out runs/jev-combined-study
```

이 문서 작성 시점에는 위 전체8슬롯 본실험을 시작하지 않았다. 호출 상한은 슬롯별 모델40·jev70이며 전체 계획에는 기존 예비4회를 포함해884회가 설정된다. 이는 상한이며 실제 사용량이 아니다. 키는 공통 저장소의 ignored `.env`에서 애플리케이션이 읽으며 프롬프트·보고서·명령행에 넣지 않는다.

질문 문구·Choice 보기 순서·임계값·정책의 해시와 검증 인증서 파일의 SHA가 일치해야 활성화된 프로필로 실행할 수 있다. 이 항목을 변경하면 기존 인증서를 재사용하지 않는다.

## 확인한 범위

실제 GLM Flash를 이용한 ALS·AML 제한 검증에서 검증 전략을 제거한 답변의 동일 작성자1회 수정과 jev 재검사가 완료됐다. AML의 반증 충실도 해석은 문단 삭제만으로 확정하기 어려웠다. 작은 인위적 예시에서의 성공을 실제 가설 전체의 검출 성능으로 확대 해석하지 않는다.
