# ALS 시간 제한 완화 재시도 — 2026-10-07

**상태: ALS 다중 모델 생성과 별도 LLM 평가 완료.** 네트워크가 허용된 현재 세션에서 DNS 조회와 실제 모델 응답이 정상 작동했다. 초기 가설부터 새로 실행했으며 이전 시도의 가설을 재사용하지 않았다.

접속 확인 질문은 GPT `gpt-6.1-sol`/xhigh, Grok `grok-4.7`/xhigh, GLM `glm-5.3-flash`/max 각각 한 번씩 성공했다. 응답 시간은 각각 4.521초, 1.861초, 0.935초였다. 앞선 제한 환경에서의 DNS 오류 기록은 그대로 보존했다.

[접속 확인 기록](evidence/2026-10-07-als-timeout-retry/connectivity.json), [실제 재시험 상태](evidence/2026-10-07-als-timeout-retry/retry.json), [동결 설정](evidence/2026-10-07-als-timeout-retry/frozen-plan.json).

이번 재시험의 생성 상한은 45분·보고 토큰 80만·최대 40회이며, 요청별 상한은 남은 실행 예산까지다. 생성은 **27분 12.908초**, 별도 평가까지 **28분 33.019초**에 끝났다. 생성·비판 30회와 별도 LLM 2회가 모두 성공했고 형식 재시도나 사용량 미확인 호출은 없었다. 생성 토큰은 403,119개, 별도 평가 포함 토큰은 443,194개다. 접속 확인 3회·7,287토큰을 별도로 합치면 새 작업 전체는 **35회·450,481토큰**이다.

가장 오래 걸린 요청은 두 번째 라운드의 Grok 개선 가설(509.639초)이다. 이는 이전 개별 요청 상한 600초보다 짧다. 이번에는 새 가설·새 진화 경로로 실행했으므로, 완료됐다는 사실만으로 시간 상한 확대의 인과 효과를 확정하지 않는다.

## 별도 LLM 평가

생성에 참여하지 않은 `deepseek-v4.1-flash`/high가 익명 가설 7개를 정방향·역방향으로 두 번 평가했다. GPT 단독의 초기·최종 답이 같아 8개 단계 연결이 7개 고유 가설로 묶였다. 단독 모델 본문은 이전 완료 결과 그대로이며, 아래 점수는 이번 공통 익명 묶음에서 새로 평가한 값이다. 지난 보고서의 별도 평가 수치와는 구분한다. 아래 수치는 다섯 평가 항목과 두 순서의 **설명용 평균**이다. 두 순서는 순서 편향 확인이며 독립 반복 실험이 아니다.

## 문헌 확인과 전문가 자료

초기 GPT 가설의 NUP98 Ser606은 실제로 보고된 인산화 자리다. 확인한 2016년 연구는 PEST 영역의 S606과 APC/C(Cdc20) 결합 조절을 다뤘다. 이 결과가 ALS 운동뉴런의 pore-retention 결함을 입증하는 것은 아니다. [Salsi et al., 2016](https://pubmed.ncbi.nlm.nih.gov/27097363/).

CDK1 등 여러 kinase에 의한 NUP98 인산화와 핵공 해체는 유사분열 연구에서 보고됐다. 이를 분열하지 않는 ALS 운동뉴런의 시작 병변으로 옮기는 연결은 가설로 남는다. [Laurell et al., 2011](https://pubmed.ncbi.nlm.nih.gov/21335236/).

이 문헌 확인은 분석자 참고 확인이며 포괄적인 신규성·모든 주장 검증이 아니다. 추가 확인 결과는 생성 모델이나 별도 평가 모델에 공급하지 않았고 공통 입력은 바꾸지 않았다.

[문헌 확인 범위와 근거](evidence/2026-10-07-als-timeout-retry/literature-spotchecks.json), [전문가용 익명 묶음](evidence/2026-10-07-als-timeout-retry/expert-only.zip). 익명 묶음에는 가설·공통 문헌·빈 평가 양식만 있으며 모델·단계·내부 점수·비교 그래프는 포함하지 않는다.
