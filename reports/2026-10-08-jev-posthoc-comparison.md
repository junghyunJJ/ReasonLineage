# ALS·AML jev 사후 검사와 DeepSeek 비교 — 2026-10-08

**검사 완료: jev-1.13.0 실제 호출 240회, 실패 0회. 기존 가설 생성은 재실행하지 않았다.**

루트 `.env`의 `JEV_API_KEY`를 메모리에서 읽어 사용했다. 셸의 `source`, 로그인 셸, 환경값 출력은 사용하지 않았다. 키·인증 헤더·`.env` 원문을 결과 자료에 저장하지 않았고, 새 자료 전체에서 실제 키 문자열이 없음을 확인했다. 이 검사 경로는 HTTP 오류의 본문과 문구도 출력하지 않는다. `.env` 권한은 기존 `600`을 유지했다.

## 검사 범위와 비교 방법

| 구분 | 대상 | 검사 내용 |
|---|---:|---|
| 기본 답변 검사 | 가설 80개 | 기존 J1의 답변 유형·구체적 근거·근거 범위, J2의 표현 과장 |
| 비판 검사 | 비판 160건 | 기존 J2의 비판에 적힌 가장 심각한 문제의 분류 |
| DeepSeek와 같은 5축의 참고 평가 | 고유 초기·최종 가설 14개 | 근거성·인과 논리·구체성·검증 가능성·실현 가능성 |
| 초기·최종 비교 연결 | 16개 | ALS·AML × 다중/GPT/Grok/GLM × 초기/최종 |

ALS는 10월 7일 완료한 다중 모델과 기존 완료 단독 3개, AML은 기존 완료 다중 모델과 10월 8일 완료 단독 3개를 사용했다. 각 실행의 가설 10개와 비판 20건을 검사했다. 선택된 초기와 최종이 같은 ALS/GPT 및 AML/GLM은 같은 평가 결과를 재사용했다.

jev는 과학 평가 대상에 기존 DeepSeek와 동일한 가설 본문 및 동결 문헌을 받았다. 모델명·진화 단계·내부 점수·작성자의 자기 점수는 요청에서 제외했다. jev 요청에는 가설 제목도 포함했다. 기본 검사의 근거 질문은 제목을 알아야 하기 때문이다. 추가 5축은 사용자 정의 사후 질문이며, jev의 기본 J1/J2가 자동으로 과학적 품질을 점수화한 것은 아니다.

DeepSeek는 7개 고유 가설을 함께 받아 정방향·역방향 두 번 1–5 정수로 평가했다. jev는 가설마다 한 번 평가하고 각 수준의 확률 분포를 반환했다. jev의 0–4 수준 기대값에 1을 더해 1–5로 표시했다. 아래 수치는 5축의 설명용 평균이다. 질문 묶음, 단독/배치 평가, 반복 수, 척도 보정이 서로 달라 점수 차이가 어느 평가자의 정확성을 입증하지 않는다. 기존 DeepSeek를 다시 호출하지 않았으며 평가 결과도 변경하지 않았다.

DeepSeek 원문은 최종의 정량 기준·시간점·대조 실험을 높게 평가하면서도, CDK5–NUP98와 발병 순서는 문헌 묶음에서 확인되지 않았고 여러 단계의 실험 및 모델의 ALS 관련성에 한계가 있다고 적었다. jev는 구체성과 검증 가능성이 조금 오르는 대신 근거성·인과 논리·실현 가능성이 내려가는 분포를 반환했다. **실험 계획의 구체화와 뒷받침된 과학적 근거의 증가는 서로 다를 수 있다는 해석**이다. jev는 자유 서술형 이유를 반환하지 않았으므로 그 평가자의 정확한 판단 이유를 확인한 것은 아니다.

AML 다중 모델에서도 DeepSeek는 더 정교해진 기전 구분·반증 조건을 높게 평가하면서 약물별 연결 고리와 노출 수준은 문헌에서 확인되지 않았다고 적었다. jev의 5개 축은 모두 낮아졌다. 구체적인 조건이 추가된 것이 근거와 실행 부담까지 개선했는지 전문가가 우선 확인할 사례다.

최종 결과의 상대 순서도 달랐다. ALS에서 DeepSeek는 Grok을 가장 높게, jev는 GLM을 가장 높게 평가했다. AML에서는 두 평가 모두 Grok이 가장 높지만, jev의 Grok 4.11과 GPT 4.06 차이는 작다. 이 순서를 모델의 확정적인 능력 순위로 사용하지 않는다.

## 기본 점검이 알려주는 것

| 항목 | ALS | AML |
|---|---:|---:|
| 기본 J1 재작성 기준 미달 | 0/40 | 0/40 |
| 답변 유형에서 정상 답변 확률 범위 | 0.95–0.99 | 0.96–0.99 |
| 구체적 근거가 있다는 확률 범위 | 0.64–0.98 | 0.95–0.98 |
| 표현 과장 평균 /4, 낮을수록 적음 | 0.61 | 0.51 |

기존 기본 기준은 정상 답변 확률 0.5, 구체적 근거 확률 0.5다. 가설 80개 모두 두 기준을 통과했다. 이는 답변에 근거 논리가 적혀 있다는 검사이며, 그 논리가 사실인지·새로운지·임상적으로 효과적인지를 확인한 결과는 아니다. 이번 검사는 사후 검사이므로 원래 진화에서 재작성하거나 후보 선택을 바꾸지 않았다.

비판 160건의 최빈 분류는 critical 150건, major 10건이었다. ALS는 critical 74/80, AML은 76/80이었다. **이 질문은 비판문이 어떤 심각도의 문제를 주장하는지 분류한다. 비판이 맞는지 판정하거나 가설 150개가 틀렸다는 뜻이 아니다.** 분류가 critical에 크게 몰려 후보를 구별하는 정보는 제한적이며, 실제 심각도는 전문가 확인이 필요하다. 임상 결과 언급(outcome_mention)은 확인된 정답 약물·임상 결과 목록이 없으므로 호출하지 않았다.

## 사용량·원본 보존·다음 실행

새 jev 요청 240회, 보고 입력 토큰 370,020개, 출력 토큰 16,758개, 합계 386,778개다. 실제 요청 묶음은 9.137초에 완료했다. 비용 필드는 반환되지 않아 실제 청구액은 알 수 없다. 사용량은 기존 생성·DeepSeek 평가와 별도 묶음으로 기록했다. 새 생성 호출 0회, 새 DeepSeek 호출 0회다.

읽은 원본 28개 파일의 검사 전후 해시와 현재 해시가 일치한다. 원본 문헌, 생성 이벤트, DeepSeek 평가와 익명 전문가 자료를 변경하지 않았다. 별도 출력 폴더만 추가했다. 검사 실행 도우미를 제외한 core 알고리즘과 기존 설정은 수정하지 않았다.

이번 `.env` 연결은 사후 검사 도우미에 적용했다. 기존 파일럿의 생성 중 J1 검사가 자동 활성화된 것은 아니다. 앞으로 jev 판단으로 가설을 고치고 그 뒤의 진화를 관찰하려면 생성 경로에 gate를 연결한 별도 실험이 필요하다. 현재 요청의 완료 기준은 기존 결과에 검사 결과와 비교를 추가하는 것이며, 전문가 평가는 계속 대기 중이다.

검사 도우미 회귀 검증 및 관련 검사: 24개 통과. 프로젝트 전체 오프라인 검증: 738개 통과, live 3개 제외. 실제 서비스는 위 240개 완료 응답으로 별도 확인했다.
