# jev 관문 프로필 0.6

초기3·이후4 구성에 jev J1/J2를 연결한 프로필이다. 새 `--jev` 실행 경로에서 DeepSeek 생성·점검·별도평가 호출은 없다. 이전 프로필과 이전 결과는 보존한다.

## 재작성 기준

| jev 질문 | 재작성 조건 |
|---|---|
| 답변이 질문에 대한 정상 답변인가 | 정상 답변 확률 <0.5 |
| 선택한 가설에 구체적인 이유·기전·근거 연구가 적혀 있는가 | 논증이 있다는 확률 <0.5 |
| 논증 충실도 | 기록만 하고 재작성 기준에는 사용하지 않음 |

두 관문 조건 중 하나라도 해당하면 같은 작성자가 한 번 다시 쓴다. 0.5와 같은 값이면 통과다. 논증 질문은 답변에 논증이 있는지를 확인하며, 그 내용의 진실·검증 여부·신규성·강도는 판정하지 않는다. 명시한 가설적 기전도 논증으로 인정한다. 과학적 품질은 작성자 외 두 모델이 별도로 평가한다.

재작성 후 다시 검사한다. 여전히 결함이어도 원 설계에 따라 기록하고 패널 채점으로 넘긴다. 반복 재작성·후보 삭제·jev 점수에 따른 fitness 또는 선택 변경은 없다. 재작성 원문과 수정문 모두 호출 기록에 저장한다. 수정문이 원문과 같아도 두 시도의 판정과 잔여 결함을 기록하고 API 판정은 재사용할 수 있다.

## 검증과 진단

첫 질문 문구는 정상6·의도결함24, 합계30개 중 정상1개를 오탐했다(29/30). 이를 보존했다. 논증의 존재와 과학적 검증 여부를 구분하도록 문구를 명확히 한 뒤, 같은 개발 예시30개와 새 표현의 별도 예시30개가 모두 기대 판정과 일치했다. 임계값0.5는 바꾸지 않았다.

`calibration.json`의 검증 결과·문항·임계값·버전과 SHA가 일치해야 활성화할 수 있다. 문항이나 임계값이 달라지면 다시 검증해야 한다. 이 작은 수동 구성 예시는 실제 가설의 과학적 타당성이나 일반적인 분류 정확도를 입증하지 않는다.

J2는 최종적으로 채점한 가설의 문체와 패널 비판의 심각도를 기록한다. 임상 결과 언급은 확인된 정답 목록이 없어서 생략한다. J2 값은 점수·선택·재작성에 사용하지 않는다.

점검 요청 실패는 판정 불가로 기록하고 원 설계처럼 생성·진화를 계속한다. J1/J2 상태를 `partial`로 표시하며 완료 검사로 보고하지 않는다. jev 응답 버전이 고정한 `jev-1.13.0`과 다르면 상태를 저장한 뒤 연구 전체의 다음 슬롯도 중단한다.

## 실행과 기록

```bash
# 계획만 출력하며 외부 모델을 호출하지 않음
python scripts/run_co_scientist_pilot.py --jev

# 별도의 새 실제 실험을 시작하는 명령
python scripts/run_co_scientist_pilot.py --jev --run --out runs/co-scientist-jev-gate-2026-10-08
```

초기에는 GPT·Grok·GLM Flash가 하나씩 작성한다. 이후 생존2+변이1+교차1을 유지한다. 초기 이후3세대 동안 가설9개를 만든다. 작성·패널심사는 정상27호출이며 재작성은 가설마다 최대1회다. jev J1은 최초9회 및 재검사 최대9회, J2는 가설문체9회와 비판18회다. 동일 텍스트는 캐시로 요청이 줄 수 있다. 생성 호출상한40과 jev 호출상한50을 구분하고 전역 사용량에도 모두 포함한다.

`checks.jsonl`에는 J1 판정·재작성 사유·시도별 결과가 저장된다. `diagnostics/j2.jsonl`에는 진단 결과가 저장된다. `checker-calls.jsonl`에는 공개 요청·확률·사용량만 기록한다. `status.json`은 생성 사용량과 `checker_usage`를 분리하고, 전역 `study.json`은 두 종류를 합한다. 전문가 자료는 별도 익명 양식으로 남으며 전문가는 아직 평가하지 않았다.

기본 키 경로는 git 공통 저장소 루트의 `.env`이며 `JEV_API_KEY`만 직접 읽는다. 셸을 실행하거나 값을 확장하지 않는다. 키·인증 헤더는 저장하지 않으며 공급자 오류 본문도 출력하지 않는다. 검증 스크립트의 `--env`는 사용자가 명시적으로 선택한 다른 dotenv 경로를 지원한다.

실제 Jev 최소검증은 완료했다. 이 프로필로 실제 ALS·AML 생성 재시험은 아직 시작하지 않았다.
