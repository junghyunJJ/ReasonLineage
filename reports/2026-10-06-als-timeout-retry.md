# ALS 시간 제한 완화 재시도

2026-10-07 갱신: 네트워크 허용 환경에서 세 모델 접속 확인과 실제 ALS 다중 모델 재시험·별도 평가를 완료했다. 최신 수치와 비교 제한은 [2026-10-07 결과](2026-10-07-als-timeout-retry.md)에 있다. 아래 접속 차단 기록은 2026-10-06 시도의 역사 기록이다.

상태: **접속 확인 단계에서 차단**. 실제 모델 호출 **0회**, 새 가설 **0개**다. 기존 결과와 단독 모델 세 결과는 그대로 유지했다.

사용자가 승인한 새 시도는 ALS 다중 모델 한 개다. 기존 프로필0.4의 요청 상한2700초를 사용하며 실행별45분·보고토큰80만·최대40호출로 제한한다. 정상 생성은30호출이다. 완료됐을 때만 기존ALS 단독모델과 비교하고 별도LLM을 정방향·역방향 두 번 호출한다. 평가·정리를 포함한 새 작업의 상한은60분·42호출이다. 이전 실험의 시계와 수치를 바꾸지 않는다.

실제 재실행 명령을 실행했지만, 현재 제한된 환경에서 chatgpt.com·api.x.ai·ollama.com 모두 `[Errno -3] Temporary failure in name resolution`이 발생했다. 인증된 모델 요청을 보내기 전에 멈췄다. 이번 기록을 모델의 가설 실패나 45분 시간 초과로 분류하지 않는다.

보조 실행 코드의 새 테스트3개와 관련기존검증을 합쳐53개가 통과했다. 전체검증은 기존 `test_one_retry_recovers_a_flaky_call` 구간에서 오래 멈춰 중단했고, 그 테스트의 별도확인도15초 상한에 도달했다. 현재 환경에서 전체검증이 통과했다고 주장하지 않는다. 기존CLI 구현은 수정하지 않았다. Git메타데이터가 읽기전용인 환경이므로 새 보조파일은 로컬에 남겨두었다.

실제 가설생성·비교·별도LLM 평가는 외부모델접속이 가능한 환경에서 위명령을 실행해야 진행된다. 기본명령은 매번 새 출력폴더를 선택하며 기존기록을 덮어쓰지 않는다.
