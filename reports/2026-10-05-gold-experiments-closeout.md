# 기존 정답지 실험 마무리 기록

날짜: 2026-10-05. 구현 기준: `gold-weather-l3`의 `f3c33ed`와 프로토콜 1.0.5.

이 기록은 기존 엔진과 정답지 실험을 로컬 `main`에 통합하고, 다음 Co-Scientist 파일럿을 별도 브랜치와 워크트리에서 시작하기 위한 기준 자료다. 현재 엔진의 구현 완료와 연구 가설의 효과 입증을 구분한다. 신규 모델 호출이나 생물학적 실험은 이번 마무리 작업에 포함하지 않는다.

## 구현과 검증

엔진은 초기 답 생성, 작성자를 제외한 심사, 차원별 중앙값과 가중 합으로 계산한 fitness, 생존자 선택, 변이와 교차, 세대 제한, 기록 재사용과 재개를 구현했다. `main`에 없는 변경에는 합성·bioRxiv·장바구니·날씨 과제 생성기, 정답 비교 도구, 실행 스크립트와 기존 실행에서 발견한 프로세스 종료·스트림 대기 수정이 포함된다. 마무리 시작 당시 `main` 대비 71개 커밋이었다.

이번 환경에서는 `python -B -m pytest -q -p no:cacheprovider`로 **651 passed, 3 deselected (20.08s)**를 확인했다. 실제 모델이나 서비스에 접속하는 `live` 테스트 3개는 제외했다. 이전 격리 환경에서 멈췄던 CLI·프로세스 테스트도 동일 코드로 **13 passed (2.42s)**를 확인했다. 격리 해제 후 통과한 관찰만으로 특정 엔진 결함을 단정하거나 소스를 수정하지 않았다.

전체 결과는 [tests-feature.txt](evidence/2026-10-05-gold-experiments/tests-feature.txt)에 보존했다. 병합된 `main`은 651 passed, 3 deselected (20.05s), 새 워크트리는 651 passed, 3 deselected (20.27s)로 동일 오프라인 검증을 통과했다. 각각 [tests-main.txt](evidence/2026-10-05-gold-experiments/tests-main.txt)와 [tests-worktree.txt](evidence/2026-10-05-gold-experiments/tests-worktree.txt)에 보존했다.

## 날씨 2단계: 진화 전후

과제는 2026년 7·8월 미국 주 세 곳의 기온 또는 강수량이 각 주의 1901~2000년 해당 월 평년보다 얼마나 높았는지 순위를 추정하는 문제다. 실제 관측 수치는 입력에 없고, 검색과 도구도 사용하지 않았다. 모델에게 필요한 정보를 제공하는 복잡한 문제와 동일하게 해석할 수는 없다.

37과제는 v1의 유효한 17개와 v2의 20개다. v1의 08·10·20은 세 후보 모두 평년보다 강수량이 적어 원 질문의 전제가 성립하지 않아 제외했다. 정답 점수는 실제 편차가 가장 큰 주를 1위에 놓으면 1, 2위면 0.5, 3위면 0이다. 이 점수와 LLM이 매긴 심사 점수 fitness는 별개다.

| 비교 | 값 |
|---|---:|
| 초기 심사 1위 답의 평균 정답 점수 | 0.7027 |
| 최종 심사 1위 답의 평균 정답 점수 | 0.7162 |
| 평균 변화 | +0.0135 |
| 좋아짐 / 나빠짐 / 동일 | 4 / 4 / 29과제 |
| 단측 부호검정 p (각 방향) | 0.6367 |
| 사전 판정 | no change |

평균 fitness는 세대별 약 0.585 / 0.637 / 0.639 / 0.640이었다. 이는 보조 기술통계이고, 세대별 신규 답의 구성도 다르므로 정답 개선이나 편향의 인과 효과로 바로 해석하지 않는다.

## 날씨 3단계 A: 심사 조건

기준선은 작성자를 제외하고 추가 맥락 없이 심사하는 `recuse + isolated`이다. 조건별로 평균 정답 점수 변화의 절대값이 0.10 이상이고, 해당 방향의 단측 부호검정 p가 0.0125 미만이어야 차이가 있다고 판정하기로 실행 전에 고정했다.

| 조건 | 선택된 답의 평균 정답 점수 | 기준선 대비 평균 변화 | 좋아짐 / 나빠짐 | 판정 |
|---|---:|---:|---:|---|
| self | 0.6216 | −0.0811 | 5 / 11 | no difference |
| shared_trace | 0.7162 | +0.0135 | 2 / 2 | no difference |
| all | 0.6757 | −0.0270 | 0 / 2 | no difference |
| author_label | 0.7162 | +0.0135 | 2 / 2 | no difference |

네 조건 모두 37/37과제를 완료했고 누락 과제와 이상 기록은 없었다. `check_l3.py`의 보존된 검사 결과는 `problems: none`이었다. 네 조건 모두 판정 기준을 충족하지 않아 사전 설계에 따라 B단계는 실행하지 않았다.

`no difference`는 동등성을 입증했다는 뜻이 아니다. 또한 `shared_trace`는 초기 세대에서 모든 답이 아직 채점 전인 상태였으므로, 누적 점수를 공유하는 장기 진화의 효과를 검증한 결과로 확대할 수 없다. `all`은 다른 저자 심사도 새로 생성하여 기준선과의 비교에 재생성 변동이 섞인다.

## 보류 항목과 재사용 조건

독립 검토는 백업·원본·복사 기록의 체크섬과 원시 실행 기록의 집계를 재확인했고, 현재 보존 자료와 측정 결과의 병합을 막는 문제는 발견하지 않았다. 검토 범위와 판단은 [premerge-review.md](evidence/2026-10-05-gold-experiments/premerge-review.md)에 남겼다.

특히 기존 출력 폴더의 조건 검사는 향후 재사용에 중요한 항목이다. 이번 측정의 조건 일관성은 사후 검사로 확인했으므로 현재 결과에는 영향이 없지만, **다음 측정에서 이 스크립트를 재사용하기 전에 기존 헤더의 조건을 검증하는 보호 절차가 필요하다.** 이번 마무리는 측정 당시 구현을 보존한다.

- 조건 실행 스크립트가 기존 출력 폴더의 `judges/context`를 직접 검사하지 않는다. 이번 실행은 상위 스크립트가 조건을 고정하고 사후 검사로 확인했다.
- 비교 출력이 중복 실행을 직접 표시하지 않는다. 별도 검사 스크립트가 확인했다.
- 재개 시 시작 실패도 재시도 한도에 포함되어 긴 장애 때 과제가 제외될 수 있다. 이번 3단계에는 누락이 없었다.
- `analyze_l3.py`는 비교 쌍이나 Grok 답이 0개인 입력을 처리하지 못한다. 이번 입력에는 해당하지 않았다.

독립 검토에서 지적한 이전 계획 문서와 테스트 파일 각각 한 곳의 EOF 공백은 동작에 영향이 없어 변경하지 않았다.

이전 세트의 다른 보류 사항과 실행 중 판단은 원본 [source-notes](evidence/2026-10-05-gold-experiments/source-notes/)에 보존했다. 이번 마무리에서 실험 프로토콜이나 이미 측정한 자료를 바꾸지 않았다.

## 원자료 보존과 다음 작업

원래 `runs/`와 `.superpowers/sdd/`는 이 체크아웃에 그대로 둔다. 현재 마무리 작업의 임시 디렉터리를 제외한 기존 기록 7,740개 항목을 로컬 `.archives/2026-10-05-gold-experiments/raw-records.tar.gz`에 백업했다. 압축 파일 크기는 40,361,413바이트이며 SHA-256은 `6f410b78b811549b6dada69b5f835a660391a7efb7605bb16c886b633b839d22`이다. 각 파일 내용, 원본과의 동일성, 링크 대상, 전체 목록을 검증했다.

[archive-manifest.json](evidence/2026-10-05-gold-experiments/archive-manifest.json)은 백업 경로·체크섬·항목 수를 기록한다. 상세 파일 목록은 로컬 백업 옆의 `file-inventory.json`에 있고 그 체크섬도 매니페스트에 있다. Git에는 압축 원자료를 넣지 않는다. 다른 기계에는 이 로컬 백업을 별도로 옮겨야 전체 기록을 복구할 수 있다.

로컬 `main` 병합 커밋은 `3b58bc4`이며 사전등록 이력을 포함한 일반 병합이다. 병합된 `main`에서 `co-scientist-pilot` 브랜치와 `.worktrees/co-scientist-pilot`을 만들고 전체 오프라인 검증을 통과했다. 병합된 `gold-weather-l3` 브랜치만 삭제했고 다른 브랜치는 유지했다. 본 체크아웃은 `main`과 기존 원자료의 보존 위치로 유지하며, `gb.html`의 내용이 그대로임을 체크섬으로 확인했다. 원격 푸시와 공개 배포는 하지 않았다.

[integration.json](evidence/2026-10-05-gold-experiments/integration.json)은 커밋·경로·검증 결과와 구현 및 측정 데이터의 Git 객체 동일성을 기록한다. 마지막 완료 기록 커밋은 문서·증거 파일만 갱신하며, 새 브랜치도 이 커밋으로 fast-forward하여 같은 기준으로 시작한다.

새 워크트리의 로그인 셸 초기화에서 키 파일의 값이 오류 메시지로 도구 출력에 나타났다. 이후 명령은 로그인 초기화 없이 실행했고, 버전 관리되는 보고서와 테스트 출력에는 해당 형식의 키값이 없음을 확인했다. 전역 셸 설정이나 자격증명 파일은 이번 작업에서 수정하지 않았다. 노출된 자격증명은 별도로 교체하는 것이 권장된다.

Co-Scientist의 ALS 입력 예시와 AML 약물 재창출 문제 중 첫 과제, 공통 근거 자료, 독립적인 초기·최종 평가 기준은 아직 선택하지 않았다. 논문과 공개된 출력은 이미 모델이 알고 있을 수 있어 새 발견의 증거와 구분해야 한다. 관련 논문: [Accelerating scientific discovery with Co-Scientist](https://www.nature.com/articles/s41586-026-10644-y).
