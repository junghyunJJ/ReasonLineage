# Co-Scientist 비교 파일럿: 인터뷰 결정사항

날짜: 2026-10-05. 작업 브랜치: `co-scientist-pilot`.
상태: 사용자와 합의한 설계 결정 기록. 새 과제 구현과 가설 생성 실험은 아직 시작하지 않았다.

## 목표와 비교 범위

핵심 목표는 동일한 자료와 비슷한 전체 연산 예산에서 ReasonLineage가 단일 모델의 반복 수정보다 좋은 연구 가설을 만드는지 확인하는 것이다. 초기 답에서 최종 답까지의 변화는 보조로 확인한다.

첫 파일럿은 다음 두 연구 문제를 모두 포함한다.

- ALS 기전 가설 생성: Co-Scientist 보충자료 Note 10의 공개 입력·중간 검토 예시를 참고한다. 본문의 실험 검증 사례와 구분한다.
- AML 약물 재창출 가설 생성: Co-Scientist 본문의 약물 재창출 연구 목표를 참고한다. 기존 repoDB의 승인 약 고르기 문제를 그대로 재사용하지 않는다.

각 문제에서 다섯 방법을 비교한다.

| 방법 | 작업 방식 |
|---|---|
| ReasonLineage | 네 모델의 후보 생성·상호 비판·선택·변이·교차 |
| GPT 단독 | GPT만으로 초안·자기 비판·반복 수정 |
| Opus 단독 | Opus만으로 같은 단독 작업 |
| Grok 단독 | Grok만으로 같은 단독 작업 |
| GLM Flash 단독 | GLM Flash만으로 같은 단독 작업 |

각 방법을 문제마다 1회씩 실행하므로 최종 산출물은 2 × 5 = 10개다. 여기서 1회는 초안부터 내부 비판·수정과 최종 선정까지의 전체 실행을 뜻한다. 이 단계는 동작과 평가 절차를 확인하는 작은 파일럿이며, 두 문제의 단회 실행으로 일반적인 성능 우위를 입증했다고 주장하지 않는다.

## 자료와 독립 평가

가설 생성·수정에는 양쪽에 동일한 검증된 고정 문헌 자료를 제공한다. 생성 단계의 자율 웹 검색은 첫 파일럿에 포함하지 않는다. 자료의 목록·내용·버전을 실행 전에 고정한다. Co-Scientist의 공개 출력은 생성 입력에 섞지 않고 비교 참고 자료로 구분한다. 모델의 기존 학습 기억에 공개 결과가 포함됐을 가능성은 남는다.

사용자는 전문 지식을 갖춘 평가자가 있다고 확인했다. 전문가 블라인드 평가를 주 평가로 하고 다음 두 평가도 별도로 수행한다.

- 문헌 검증: 근거의 존재와 주장 뒷받침 여부를 확인한다.
- 별도 LLM 평가: 가설을 생성·선택하는 모델들과 분리한 평가자를 사용한다.

전문가용 산출물은 작성 모델·방법·초기/최종 단계가 드러나지 않도록 익명화한다. 세 평가 결과를 별도로 보고하며 내부 fitness를 독립 평가 결과로 대신하지 않는다. 독립 평가의 결과는 완료된 생성 실험의 수정·선택에 되먹임하지 않는다.

## 모델 설정

새 실험의 설정 파일은 `configs/co-scientist-pilot.json`이다. 기존 `configs/main.json`과 이전 실행 기록은 변경하지 않는다.

| 이름 | 모델 | 추론 수준 |
|---|---|---|
| opus | claude-opus-5-5 | xhigh |
| gpt | gpt-6.1-sol | xhigh |
| grok | grok-4.7 | xhigh |
| glm | glm-5.3-flash | max |

GLM Flash 선택은 사용자 지시다. 2026-10-05에 기존 공급자 `https://ollama.com/v1`의 인증된 모델 목록에서 정확한 식별자 `glm-5.3-flash`를 확인했다. 모델 생성 요청은 보내지 않았다. 공급자의 공개 설명은 Flash의 추론 수준을 low/high/max로 안내하므로 GLM은 max를 기록한다. 실제 요청의 옵션 지원과 구조화 출력은 실행 전 별도 확인할 사항이다.

ReasonLineage에 들어가는 네 모델의 사용량을 합친 총예산을 각 단독 방법의 예산과 비교한다. 생성뿐 아니라 내부 비판·선택·수정 비용도 포함한다. 서로 다른 모델의 토큰 수가 실제 계산량과 같다고 가정하지 않고 사용량·시간·확인 가능한 비용을 함께 기록한다.

## 실행 설계에서 구체화할 항목

- 두 과제의 정확한 질문, 고정 문헌 자료와 전문가 평가 문항.
- 독립 LLM 평가자, 판정 규칙과 익명화 방식.
- 방법별 호출·토큰 예산과 전체 실행 상한, 실패·재개 규칙.
- 단독 반복 수정 실행기와 기존 진화 실행기의 예산 비교 방식.

이번 변경은 설계 결정과 모델 설정을 기록하는 준비 작업이다. 가설 생성 실험, 전문가에게 자료 전송, 독립 평가 실행은 아직 수행하지 않았다.
