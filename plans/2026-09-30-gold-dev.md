# 정답지 개발용 세트 (repoDB) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 첫 세대(0세대) 답의 심사 점수(적합도)가 정답을 따라가는지 보는 1단계를 실측한다. repoDB와 ClinicalTrials.gov 검색으로 개발용 과제 10개와 정답 파일을 만들고, 엔진을 0세대(첫 세대)까지만 돌린 뒤 `reasonlineage gold`로 판정한다.

**Architecture:** 엔진은 정답을 보지 않는다. 정답지 도구는 두 곳에 있다. `src/reasonlineage/gold/`는 repoDB 추출, ClinicalTrials.gov 검색과 임상 기록, 과제·정답 파일 만들기를 맡고, `src/reasonlineage/diagnose/gold.py`는 실행이 끝난 뒤의 채점과 판정을 맡는다. `core/`, `engine/`, `checks/`는 이 둘을 import하지 않고, 테스트로 확인한다. 엔진 쪽 변경은 세 가지다: 세대 수 0 허용, `--replay`의 세대 수 덮어쓰기와 과제 확인, `python -m reasonlineage`. 후보·임상 기록·검수 기록·과제·정답 파일은 저장소에 넣고, repoDB 원본은 저장소 밖 캐시에 둔다.

**Tech Stack:** Python 3.11 이상, 표준 라이브러리만(csv, hashlib, json, math, random, re, urllib), pytest, bash. 외부 자료는 repoDB 고정 커밋(raw.githubusercontent.com)과 ClinicalTrials.gov API v2다.

**Spec:** `specs/2026-09-30-gold-dev-design.md` (엔진은 `specs/2026-09-29-engine-design.md`)

**미리 확인한 것:**
- 이 계획의 코드는 워크트리를 임시 폴더에 복사해서 모두 짜고 돌려 봤다.
- 그다음 이 문서의 수정 지시를 새 복사본에 Task 1부터 차례로 적용했다. 단계마다 Run 명령을 돌려 아래 Expected와 같은 결과를 확인했고(RED 단계는 실패, GREEN 단계는 통과), 마지막 코드는 처음 짠 코드와 같았다. 전체 테스트는 319 passed, 3 deselected다.
- 후보 단계도 2026-09-30에 실제 repoDB와 ClinicalTrials.gov로 돌려 봤다. 적응증 39개를 검색해 후보 적응증 35개, 실패 쌍 284개(repoDB 111, 검색 173), 임상 기록 215개를 받았고, 받지 못한 기록은 없었다.

## Global Constraints

- Python 3.11 이상, `dependencies = []`(표준 라이브러리만). 테스트는 워크트리 루트에서 `python -m pytest -q`로 돌린다. `pyproject.toml`의 `pythonpath = ["src"]` 덕분에 테스트는 워크트리 코드를 쓴다.
- 작업은 워크트리 `/common/jungj2/project/ReasonLineage/.claude/worktrees/gold-standard-v0`, 브랜치 `worktree-gold-standard-v0`에서만 한다. 원래 체크아웃(`/common/jungj2/project/ReasonLineage`)은 다른 세션이 쓰므로 건드리지 않는다. 푸시하지 않는다. `gb.html`은 커밋하지 않는다.
- 워크트리에서 엔진 명령을 직접 부를 때는 `PYTHONPATH=src python -m reasonlineage …`로 부른다. 편집 가능 설치가 원래 체크아웃의 코드를 가리키기 때문이다(설계 5.3). 두 스크립트는 이 경로를 스스로 설정한다.
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`를 붙인다.
- API 키 파일(`~/.config/reasonlineage/*.env`)은 어떤 도구로도 열지 않는다(cat, source, grep, stat, 셸 변수로 읽기 포함). 키는 reasonlineage 프로그램만 읽는다.
- 이 세트의 과제는 모두 `data_sensitivity: public`이다. jev에는 공개 텍스트만 간다.
- 실제 모델을 부르는 실측(Task 11)은 구독 사용량과 jev 크레딧을 쓰므로 사용자에게 먼저 묻는다.
- repoDB: `zietzm/repoDB` 커밋 `c921b2610f596a40cee2a538de37f9f29d3dfd06`의 `data/repoDB.csv`, sha256 `c5424d26b190ea207f6d343620eea748f845b0f28cad811eaf3a158797e0ef23`(1,073,050 bytes). 캐시는 `~/.cache/reasonlineage/repodb/`이고, 원본은 저장소에 넣지 않는다.

- 1단계 판정 기준은 결과를 본 뒤 바꾸지 않는다: 천장 80%, 쌍 10개, 일치율 0.70, 적합도 동점 0.5. 판정 순서는 천장 → 쌍 부족 → 신호 있음 → 신호 없음이다.

- 오류 메시지는 무엇이 잘못됐고 무엇을 하면 되는지 말한다.

def test_replay_can_add_generations_to_a_generation_zero_run(tmp_path):
    task, setup = write_files(tmp_path)
    main(["run", task, "--config", setup, "--seed", "5", "--generations", "0", "--out", str(tmp_path / "runs")], World().services)
    (first,) = run_dirs(tmp_path)
    world = World()
    args = ["run", task, "--config", setup, "--replay", str(first), "--generations", "2", "--out", str(tmp_path / "runs")]
    assert main(args, world.services) == 0
    (second,) = [p for p in run_dirs(tmp_path) if p != first]
    options = json.loads((second / "header.json").read_text())["options"]
    assert options["generations"] == 2 and options["seed"] == 5 and options["replay_from"] == str(first)
    calls = [r for r in read_events(second / "events.jsonl") if r["event"] == "call.completed"]
    assert {r["name"].split("/")[0] for r in calls} == {"g0", "g1", "g2"}
    assert all(r["replayed"] == r["name"].startswith("g0/") for r in calls)
    assert sum(len(m.seen) for m in world.models.values()) == sum(not r["replayed"] for r in calls)


def test_replay_refuses_a_run_of_another_task(tmp_path, capsys):
    task, setup = write_files(tmp_path)
    main(["run", task, "--config", setup, "--generations", "0", "--out", str(tmp_path / "runs")], World().services)
    (source,) = run_dirs(tmp_path)
    other = json.loads((tmp_path / "task.json").read_text()) | {"question": "Which drug for a different disease?"}
    (tmp_path / "other.json").write_text(json.dumps(other))
    world = World()
    args = ["run", str(tmp_path / "other.json"), "--config", setup, "--replay", str(source), "--out", str(tmp_path / "runs")]
    assert main(args, world.services) == 1
    assert "different task" in capsys.readouterr().err
    assert run_dirs(tmp_path) == [source]
    assert all(m.seen == [] for m in world.models.values())

"""ClinicalTrials.gov: a search for stopped trials of an indication (gold design 4.3), and trial records for
the failed pairs, kept in a JSON file (gold design 4.4).

Curation reads the records to check that a failed drug was the tested drug, for the indication itself,
and stopped for efficacy or safety.
"""

import json
import re
import urllib.parse
import urllib.request
from datetime import date
from pathlib import Path
from typing import Any, Callable, Iterable

FIELDS = "NCTId,BriefTitle,OverallStatus,WhyStopped,InterventionName,InterventionType,Phase,Condition"
API = f"https://clinicaltrials.gov/api/v2/studies/{{nct}}?fields={FIELDS}"
SEARCH = "https://clinicaltrials.gov/api/v2/studies"
NCT = re.compile(r"NCT\d{8}")


class SearchError(RuntimeError):
    """ClinicalTrials.gov could not be searched."""


def _get(url: str) -> dict[str, Any]:
    with urllib.request.urlopen(url, timeout=60) as response:
        return json.load(response)


def summarize(study: dict[str, Any]) -> dict[str, Any]:
    """The fields curation needs, from one API v2 study record."""
    section = study.get("protocolSection", {})
    status = section.get("statusModule", {})
    ident = section.get("identificationModule", {})
    return {
        "nct": ident.get("nctId"),
        "title": ident.get("briefTitle"),
        "status": status.get("overallStatus"),
        "why_stopped": status.get("whyStopped"),
        "interventions": [{"name": i.get("name"), "type": i.get("type")}
                          for i in section.get("armsInterventionsModule", {}).get("interventions", [])],
        "phases": section.get("designModule", {}).get("phases", []),
        "conditions": section.get("conditionsModule", {}).get("conditions", []),
    }


def search(condition: str, get: Callable[[str], dict[str, Any]] = _get, attempts: int = 2) -> list[dict[str, Any]]:
    """Every stopped (terminated, withdrawn, suspended) interventional trial of a condition, page by page.

    A page that fails `attempts` times stops the search with a SearchError.
    """
    found: list[dict[str, Any]] = []
    token = None
    while True:
        params = {"query.cond": condition, "filter.overallStatus": "TERMINATED,WITHDRAWN,SUSPENDED",
                  "filter.advanced": "AREA[StudyType]INTERVENTIONAL", "fields": FIELDS, "pageSize": "1000"}
        if token:
            params["pageToken"] = token
        url = f"{SEARCH}?{urllib.parse.urlencode(params)}"
        for attempt in range(attempts):
            try:
                page = get(url)
                break
            except (OSError, ValueError) as exc:
                if attempt == attempts - 1:
                    raise SearchError(f"could not search ClinicalTrials.gov for {condition!r}: {exc}") from None
        found += [summarize(study) for study in page.get("studies", [])]
        token = page.get("nextPageToken")
        if not token:
            return found


def fetch_trials(ncts: Iterable[str], path: str | Path, get: Callable[[str], dict[str, Any]] = _get,
                 attempts: int = 2) -> dict[str, dict[str, Any]]:
    """A record for every NCT id, reusing the ones already saved in `path`.

    A fetch that fails `attempts` times is saved as {"error": ...} and tried again on the next call.
    Ids that are not NCT numbers (repoDB writes "NA") are skipped.
    """
    path = Path(path)
    records = json.loads(path.read_text(encoding="utf-8")) if path.exists() else {}
    for nct in sorted({n for n in ncts if NCT.fullmatch(n or "")}):
        if nct in records and "error" not in records[nct]:
            continue
        for _ in range(attempts):
            try:
                records[nct] = {**summarize(get(API.format(nct=nct))), "retrieved": date.today().isoformat()}
                break
            except (OSError, ValueError) as exc:
                records[nct] = {"error": str(exc)}
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(records, ensure_ascii=False, indent=1, sort_keys=True) + "\n", encoding="utf-8")
    return records
````

import io

import urllib.request
from collections import defaultdict

def load_rows(cache: str | Path = CACHE, download: Callable[[str], bytes] = _download) -> list[dict[str, str]]:
    """The rows of the pinned repoDB file, fetched once into `cache`."""
    path = Path(cache) / "repoDB.csv"
    if not path.exists():

            data = download(URL)
        except OSError as exc:
            raise SourceError(f"could not fetch {URL}: {exc}") from None
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(data)
    data = path.read_bytes()
    digest = hashlib.sha256(data).hexdigest()
    if digest != SHA256:
        raise SourceError(f"{path} has sha256 {digest}, not the pinned {SHA256}; delete it to fetch again")
    return list(csv.DictReader(io.StringIO(data.decode("utf-8"))))


def stop_reason(text: str | None) -> str | None:
    """'efficacy' or 'safety' when a trial's stop reason names one of them, else None."""
    if EFFICACY.search(text or ""):
        return "efficacy"
    if SAFETY.search(text or ""):
        return "safety"
    return None


def candidates(rows: Sequence[dict[str, str]], min_failed: int = 2,
               extra: dict[str, list[dict[str, str]]] | None = None) -> list[dict[str, Any]]:
    """Indications with at least one approved drug and `min_failed` other drugs whose trials for it
    stopped for efficacy or safety.

    `extra` adds failures found by a ClinicalTrials.gov search (`searched_failures`), by indication id;
    a drug and trial that repoDB already has is not added twice.
    """
    approved: dict[str, set[str]] = defaultdict(set)
    names: dict[str, str] = {}
    for row in rows:
        names.setdefault(row["ind_id"], row["ind_name"])
        if row["status"] == "Approved":
            approved[row["ind_id"]].add(row["drug_name"])
    failures: dict[str, list[dict[str, str]]] = defaultdict(list)
    for row in rows:
        reason = stop_reason(row["DetailedStatus"])
        if row["status"] in FAILED and reason and row["drug_name"] not in approved[row["ind_id"]]:
            failures[row["ind_id"]].append({"drug": row["drug_name"], "nct": row["NCT"], "status": row["status"],
                                            "phase": row["phase"], "reason": reason, "detail": row["DetailedStatus"],
                                            "source": "repodb"})
    for ind_id, found in (extra or {}).items():
        known = {(f["drug"], f["nct"]) for f in failures[ind_id]}
        failures[ind_id] += [f for f in found if (f["drug"], f["nct"]) not in known]
    pool = []
    for ind_id in sorted(failures):
        if approved[ind_id] and len({f["drug"] for f in failures[ind_id]}) >= min_failed:
            pool.append({"ind_id": ind_id, "indication": names[ind_id], "approved": sorted(approved[ind_id]),
                         "failed": sorted(failures[ind_id], key=lambda f: (f["drug"], f["nct"]))})
    return pool


def _drug_pattern(names: Iterable[str]) -> re.Pattern[str]:
    """Drug names as whole words, the longest first, so 'insulin glargine' is found before 'insulin'."""
    alternatives = "|".join(re.escape(name) for name in sorted(names, key=lambda n: (-len(n), n)))
    return re.compile(rf"(?<![a-z0-9])(?:{alternatives})(?![a-z0-9])")


def searched_failures(rows: Sequence[dict[str, str]], ind_id: str, records: Iterable[dict[str, Any]]) -> list[dict[str, str]]:
    """Failed drugs from searched trials of one indication (gold design 4.3): the trial stopped for efficacy
    or safety, and its tested drugs are all one repoDB drug that is approved for something, but not for this.

    Tested drugs are drug or biological interventions that are not a placebo; a tested drug whose name
    holds no repoDB drug, or a second drug, leaves the trial out.
    """
    names = {row["drug_name"].lower(): row["drug_name"] for row in rows if row["status"] == "Approved"}
    approved = {row["drug_name"] for row in rows if row["ind_id"] == ind_id and row["status"] == "Approved"}
    pattern = _drug_pattern(names)
    found = []
    for record in records:
        reason = stop_reason(record["why_stopped"])
        tested = [i["name"] or "" for i in record["interventions"]
                  if i["type"] in TESTED and not PLACEBO.search(i["name"] or "")]
        drugs = [{names[m] for m in pattern.findall(name.lower())} for name in tested]
        named = set().union(*drugs)
        if reason and drugs and all(drugs) and len(named) == 1 and not named & approved:
            found.append({"drug": named.pop(), "nct": record["nct"], "status": record["status"].title(),
                          "phase": "/".join(record["phases"]), "reason": reason, "detail": record["why_stopped"],
                          "source": "ctgov"})
    return found

"""Task files and the gold file from the curation record (gold design 4.5, 4.6).

The task files use the engine's task format. The gold file is separate and only the analysis
tools read it, so the engine never sees which drug is the approved one.
"""

import hashlib
import json
import random
import re
from pathlib import Path
from typing import Any, Mapping, Sequence

from . import repodb

QUESTION = ("Which of these drugs is most promising for treating {name}? Rank the candidates, "
            "and give the mechanism, the key evidence, and a validation experiment for the top pick.")


class CurationError(ValueError):
    """The curation record breaks a rule of gold design 4.5."""


def task_id(display_name: str) -> str:
    return "repodb-" + re.sub(r"[^a-z0-9]+", "-", display_name.lower()).strip("-")


def shuffled(items: Sequence[str], key: str) -> list[str]:
    """The items in an order fixed by `key`, so the approved drug is not always in the same place."""
    order = list(items)
    random.Random(int(hashlib.sha256(key.encode("utf-8")).hexdigest()[:8], 16)).shuffle(order)
    return order


def check_curation(curation: Mapping[str, Any], pool: Sequence[Mapping[str, Any]]) -> list[str]:
    """What breaks the rules in the curation record, checked against the candidate pool; empty when usable."""
    by_ind = {c["ind_id"]: c for c in pool}
    problems: list[str] = []
    seen: set[str] = set()
    ids: set[str] = set()
    for task in curation["tasks"]:
        where = task.get("id") or task.get("ind_id")
        candidate = by_ind.get(task["ind_id"])
        if candidate is None:
            problems.append(f"{where}: {task['ind_id']} is not in the candidate pool")
            continue
        if task["ind_id"] in seen:
            problems.append(f"{where}: a second task for {task['ind_id']}; one task per indication")
        seen.add(task["ind_id"])
        if task["id"] != task_id(task["display_name"]):
            problems.append(f"{where}: the id must be {task_id(task['display_name'])}")
        if task["id"] in ids:
            problems.append(f"{where}: another task has the same id; give one of them another display name")
        ids.add(task["id"])
        failed = [f["drug"] for f in task["failed"]]
        if len(failed) != 2 or len({task["approved"]["drug"], *failed}) != 3:
            problems.append(f"{where}: a task needs one approved and two different failed drugs")
        if task["approved"]["drug"] not in candidate["approved"]:
            problems.append(f"{where}: {task['approved']['drug']} is not approved for {candidate['indication']} in repoDB")
        for entry in task["failed"]:
            known = {f["nct"] for f in candidate["failed"] if f["drug"] == entry["drug"]}
            if not known:
                problems.append(f"{where}: {entry['drug']} has no efficacy or safety failure for {candidate['indication']} in repoDB")
            elif not entry["ncts"] or not set(entry["ncts"]) <= known:
                problems.append(f"{where}: {entry['drug']}'s trials must be among {sorted(known)}")
        for part in (task["approved"], *task["failed"]):
            if not part.get("why"):
                problems.append(f"{where}: {part['drug']} needs a reason ('why')")
    return problems


def build(curation: Mapping[str, Any], pool: Sequence[Mapping[str, Any]], tasks_dir: str | Path,
          gold_path: str | Path) -> list[Path]:
    """Write one task file per curated task and the gold file; nothing is written if the curation breaks a rule."""
    problems = check_curation(curation, pool)
    if problems:
        raise CurationError("; ".join(problems))
    tasks_dir, gold_path = Path(tasks_dir), Path(gold_path)
    tasks_dir.mkdir(parents=True, exist_ok=True)
    gold = {"source": {"repo": "zietzm/repoDB", "commit": repodb.COMMIT, "path": "data/repoDB.csv", "sha256": repodb.SHA256},
            "tasks": {}}
    written = []
    for task in curation["tasks"]:
        failed = [f["drug"] for f in task["failed"]]
        body = {"id": task["id"], "question": QUESTION.format(name=task["display_name"]),
                "candidates": shuffled([task["approved"]["drug"], *failed], task["id"]),
                "category": "biomedical", "data_sensitivity": "public"}
        path = tasks_dir / f"{task['id']}.json"
        path.write_text(json.dumps(body, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
        written.append(path)
        gold["tasks"][task["id"]] = {"approved": [task["approved"]["drug"]], "failed": failed}
    gold_path.parent.mkdir(parents=True, exist_ok=True)
    gold_path.write_text(json.dumps(gold, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
    return written
````

TRUTH = {"approved": ["A"], "failed": ["B", "C"]}

DIMS = ["evidenceCoverage", "specificity", "novelty", "actionability"]

def answer(cid, generation, author, ranking, fitness, operator=None):
    """One answer, judged by the three other panel models at its own fitness."""
    return {"id": cid, "generation": generation, "author": author, "ranking": ranking, "fitness": fitness,
            "operator": operator or ("seed" if generation == 0 else "mutation"),

def write_run(root, name, task_id, answers, *, finished=True, candidates=("A", "B", "C"), final=None):
    run = root / name
    run.mkdir(parents=True)
    task = {"id": task_id, "question": "Q?", "candidates": list(candidates), "category": "biomedical", "data_sensitivity": "public"}
    (run / "header.json").write_text(json.dumps({"task": task}))
    lines = []
    for a in answers:
        ranking = [{"item": i, "promisingness": 0.5, "confidence": 0.5, "pmids": []} for i in a["ranking"]]
        lines.append({"event": "candidate.created", "id": a["id"], "author": a["author"], "operator": a["operator"], "parents": [],
                      "generation": a["generation"], "versions": [], "answer": {"answer": "x", "ranking": ranking}})
        for judge, value in a["judges"].items():
            lines.append({"event": "judge.scored", "candidate": a["id"], "judge": judge, "author": a["author"],
                          "generation": a["generation"], "scores": {d: value for d in DIMS}, "critique": ["x"]})
        lines.append({"event": "candidate.scored", "candidate": a["id"], "judges": list(a["judges"]), "scores": {}, "fitness": a["fitness"]})
    (run / "events.jsonl").write_text("".join(json.dumps(line) + "\n" for line in lines))
    if finished:
        population = final or [a["id"] for a in answers]
        (run / "result.json").write_text(json.dumps({"population": [{"id": i} for i in population]}))
    return run

"""Scoring every answer of a run against a gold file, and the level-1 and level-2 summaries (gold design 5.4, 6).

This reads finished run folders and the gold file; the engine never imports it.
"""

import json
from collections import Counter, defaultdict
from itertools import combinations
from math import comb
from pathlib import Path
from typing import Any, Callable, Mapping, Sequence

from ..engine.config import task_from_dict
from ..engine.events import read_events

# Level-1 rules, fixed before any run (gold design 6.2). Do not change them after seeing results.
CEILING = 0.8
MIN_PAIRS = 10
SIGNAL = 0.7
_EPS = 1e-9


def correctness(ranking: Sequence[str], truth: Mapping[str, Sequence[str]]) -> float | None:
    """Share of (approved, failed) pairs in which the approved drug is ranked higher (gold design 6.1).
    None when the ranking leaves out a gold drug."""
    position = {item: i for i, item in enumerate(ranking)}
    if any(drug not in position for drug in (*truth["approved"], *truth["failed"])):
        return None
    pairs = [(a, f) for a in truth["approved"] for f in truth["failed"]]
    return sum(position[a] < position[f] for a, f in pairs) / len(pairs)


def score_run(run_dir: str | Path, gold: Mapping[str, Any]) -> dict[str, Any]:
    """Every answer of one finished run with its fitness, judge scores, and correctness.

    Writes diagnostics/gold.jsonl for a scored run. The status says why a run was not scored:
    not_a_run, no_gold, mismatch (the task's candidates differ from the gold drugs), incomplete.
    """
    run_dir = Path(run_dir)
    if not (run_dir / "header.json").is_file():
        return {"run": run_dir.name, "task": None, "status": "not_a_run"}
    task = task_from_dict(json.loads((run_dir / "header.json").read_text(encoding="utf-8"))["task"])
    truth = gold["tasks"].get(task.id)
    if truth is None:
        return {"run": run_dir.name, "task": task.id, "status": "no_gold"}
    if set(task.candidates or ()) != {*truth["approved"], *truth["failed"]}:
        return {"run": run_dir.name, "task": task.id, "status": "mismatch"}
    if not (run_dir / "result.json").is_file():
        return {"run": run_dir.name, "task": task.id, "status": "incomplete"}
    answers: dict[str, dict[str, Any]] = {}
    for event in read_events(run_dir / "events.jsonl"):
        if event["event"] == "candidate.created":
            ranking = [entry["item"] for entry in event["answer"]["ranking"]]
            answers[event["id"]] = {"id": event["id"], "generation": event["generation"], "operator": event["operator"],
                                    "author": event["author"], "ranking": ranking, "correctness": correctness(ranking, truth),
                                    "fitness": None, "judges": {}}
        elif event["event"] == "candidate.scored":
            answers[event["candidate"]]["fitness"] = event["fitness"]
        elif event["event"] == "judge.scored":
            weighted = sum(task.weights[dim] * value for dim, value in event["scores"].items())
            answers[event["candidate"]]["judges"][event["judge"]] = round(weighted, 4)
    result = json.loads((run_dir / "result.json").read_text(encoding="utf-8"))
    out = run_dir / "diagnostics" / "gold.jsonl"
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text("".join(json.dumps(a, ensure_ascii=False) + "\n" for a in answers.values()), encoding="utf-8")
    return {"run": run_dir.name, "task": task.id, "status": "scored", "answers": list(answers.values()),
            "final": [member["id"] for member in result["population"]], "candidates": list(task.candidates), "truth": truth}


def _concordance(groups: Sequence[Sequence[Mapping[str, Any]]], value: Callable[[Mapping[str, Any]], float | None]):
    """(agreement, pairs, concordant, discordant) over same-group answer pairs with different correctness.
    A pair where `value` is missing for either answer is left out; equal values count as half agreement."""
    agree, pairs, concordant, discordant = 0.0, 0, 0, 0
    for group in groups:
        for x, y in combinations(group, 2):
            if x["correctness"] == y["correctness"]:
                continue
            high, low = (x, y) if x["correctness"] > y["correctness"] else (y, x)
            v_high, v_low = value(high), value(low)
            if v_high is None or v_low is None:
                continue
            pairs += 1
            if v_high > v_low:
                agree, concordant = agree + 1, concordant + 1
            elif v_high < v_low:
                discordant += 1
            else:
                agree += 0.5
    return agree, pairs, concordant, discordant


def sign_test(concordant: int, discordant: int) -> float | None:
    """One-sided exact binomial p-value for at least `concordant` agreements out of the untied pairs."""
    n = concordant + discordant
    if n == 0:
        return None
    return sum(comb(n, k) for k in range(concordant, n + 1)) / 2 ** n


def level1(runs: Sequence[Mapping[str, Any]]) -> dict[str, Any]:
    """Does generation-0 fitness follow correctness? The verdict follows gold design 6.2 in order."""
    groups = [[a for a in run["answers"] if a["generation"] == 0 and a["correctness"] is not None] for run in runs]
    answers = [a for group in groups for a in group]
    unscorable = sum(1 for run in runs for a in run["answers"] if a["generation"] == 0 and a["correctness"] is None)
    share = sum(a["correctness"] == 1 for a in answers) / len(answers) if answers else 0.0
    agree, pairs, concordant, discordant = _concordance(groups, lambda a: a["fitness"])
    rate = agree / pairs if pairs else None
    if answers and share >= CEILING - _EPS:
        verdict = "hold: ceiling"
    elif pairs < MIN_PAIRS:
        verdict = "hold: too few pairs"
    elif rate >= SIGNAL - _EPS:
        verdict = "signal"
    else:
        verdict = "no signal"
    by_judge = {}
    for judge in sorted({j for a in answers for j in a["judges"]}):
        j_agree, j_pairs, _, _ = _concordance(groups, lambda a, j=judge: a["judges"].get(j))
        by_judge[judge] = {"pairs": j_pairs, "concordance": j_agree / j_pairs if j_pairs else None}
    authors: dict[str, list[float]] = defaultdict(list)
    for a in answers:
        authors[a["author"]].append(a["correctness"])
    return {"tasks": len(runs), "answers": len(answers), "unscorable": unscorable, "share_correct": share,
            "pairs": pairs, "concordance": rate, "verdict": verdict, "sign_test_p": sign_test(concordant, discordant),
            "by_judge": by_judge, "by_model": {m: sum(v) / len(v) for m, v in authors.items()},
            "rules": {"ceiling": CEILING, "min_pairs": MIN_PAIRS, "signal": SIGNAL}}


def borda(rankings: Sequence[Sequence[str]], candidates: Sequence[str]) -> list[str]:
    """One combined ranking: n-1 points for 1st down to 0 for last; ties keep the candidates' order."""
    points = {c: 0 for c in candidates}
    for ranking in rankings:
        for i, item in enumerate(ranking):
            if item in points:
                points[item] += len(ranking) - 1 - i
    return sorted(candidates, key=lambda c: -points[c])


def _mean(values: Sequence[float]) -> float | None:
    return round(sum(values) / len(values), 4) if values else None


def level2(runs: Sequence[Mapping[str, Any]]) -> dict[str, Any] | None:
    """Does evolution raise correctness? Comparisons only (gold design 6.3); None when no run evolved."""
    evolved = [run for run in runs if any(a["generation"] >= 1 for a in run["answers"])]
    if not evolved:
        return None
    per_task, generations = [], defaultdict(lambda: {"fitness": [], "correctness": []})
    for run in evolved:
        by_id = {a["id"]: a for a in run["answers"]}
        first = [a for a in run["answers"] if a["generation"] == 0]
        best_first = max(first, key=lambda a: a["fitness"])  # ties go to the earlier answer
        best_final = max((by_id[i] for i in run["final"]), key=lambda a: a["fitness"])
        vote = borda([a["ranking"] for a in first], run["candidates"])
        per_task.append({"task": run["task"], "gen0_best": best_first["correctness"], "final_best": best_final["correctness"],
                         "gen0_vote": correctness(vote, run["truth"]), "by_model": {a["author"]: a["correctness"] for a in first}})
        for a in run["answers"]:
            if a["correctness"] is not None:
                generations[a["generation"]]["fitness"].append(a["fitness"])
                generations[a["generation"]]["correctness"].append(a["correctness"])
    means = {key: _mean([t[key] for t in per_task if t[key] is not None]) for key in ("gen0_best", "final_best", "gen0_vote")}
    return {"tasks": len(evolved), "per_task": per_task, "mean": means,
            "by_generation": {str(g): {"fitness": _mean(v["fitness"]), "correctness": _mean(v["correctness"]),
                                       "answers": len(v["fitness"])} for g, v in sorted(generations.items())}}


def summarize(runs: Sequence[Mapping[str, Any]]) -> dict[str, Any]:
    scored = [run for run in runs if run["status"] == "scored"]
    tasks = Counter(run["task"] for run in scored)
    return {"runs": dict(Counter(run["status"] for run in runs)),
            "duplicate_tasks": sorted(t for t, n in tasks.items() if n > 1),
            "level1": level1(scored) if scored else None, "level2": level2(scored)}


def format_report(report: Mapping[str, Any]) -> str:
    """The summary as a few readable lines."""
    lines = ["Runs: " + ", ".join(f"{n} {status}" for status, n in sorted(report["runs"].items()))]
    if report["duplicate_tasks"]:
        lines.append("warning: tasks with more than one run: " + ", ".join(report["duplicate_tasks"]))
    one = report["level1"]
    if one:
        rate = "n/a" if one["concordance"] is None else f"{one['concordance']:.2f}"
        lines.append(f"Level 1 (generation 0): {one['answers']} answers, {one['share_correct']:.0%} fully correct, "
                     f"{one['pairs']} pairs with different correctness, concordance {rate} -> {one['verdict']}")
        if one["unscorable"]:
            lines.append(f"  {one['unscorable']} answer(s) left out a gold drug and were not scored")
        if one["sign_test_p"] is not None:
            lines.append(f"  sign test p = {one['sign_test_p']:.3g}")
        lines.append("  by judge: " + ", ".join(f"{j} {v['concordance']:.2f} ({v['pairs']} pairs)"
                                             for j, v in one["by_judge"].items() if v["concordance"] is not None))
        lines.append("  correctness by model: " + ", ".join(f"{m} {v:.2f}" for m, v in one["by_model"].items()))
    two = report["level2"]
    if two:
        mean = two["mean"]
        lines.append(f"Level 2 ({two['tasks']} evolved runs): mean correctness gen-0 best {mean['gen0_best']}, "
                     f"final best {mean['final_best']}, gen-0 vote {mean['gen0_vote']}")
        lines.append("  by generation: " + ", ".join(f"{g}: fitness {v['fitness']} correctness {v['correctness']}"
                                                  for g, v in two["by_generation"].items()))
    return "\n".join(lines)

def imports_gold(path: Path) -> bool:
    """Does the file import the gold tools, absolutely or relatively (gold design 2, criterion 2)?"""
    tree = ast.parse(path.read_text(encoding="utf-8"))

#!/usr/bin/env python3
"""Build the repoDB dev gold set (gold design 4).

    python scripts/build_repodb_dev.py candidates   # gold/repodb-dev/candidates.json and trials.json
    (Claude writes gold/repodb-dev/curation.json by the rules in gold design 4.5)
    python scripts/build_repodb_dev.py build        # tasks/repodb-dev/*.json and gold/repodb-dev/gold.json
"""

import argparse
import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "src"))  # this checkout's code, not an installed copy

from reasonlineage.gold import build, repodb, trials  # noqa: E402


def cmd_candidates(args: argparse.Namespace) -> int:
    rows = repodb.load_rows(cache=args.cache)
    base = repodb.candidates(rows, min_failed=1)
    extra = {}
    for entry in base:
        print(f"searching ClinicalTrials.gov: {entry['indication']}", flush=True)
        try:
            extra[entry["ind_id"]] = repodb.searched_failures(rows, entry["ind_id"], trials.search(entry["indication"]))
        except trials.SearchError as exc:
            print(f"{exc}; run the candidates step again", file=sys.stderr)
            return 1
    pool = repodb.candidates(rows, extra=extra)
    args.gold_dir.mkdir(parents=True, exist_ok=True)
    (args.gold_dir / "candidates.json").write_text(json.dumps(pool, ensure_ascii=False, indent=1) + "\n", encoding="utf-8")
    records = trials.fetch_trials([f["nct"] for c in pool for f in c["failed"]], args.gold_dir / "trials.json")
    missing = sorted(nct for nct, record in records.items() if "error" in record)
    searched = sum(f["source"] == "ctgov" for c in pool for f in c["failed"])
    print(f"{len(base)} indications searched; {len(pool)} candidate indications ({searched} failed pairs from the search), "
          f"{len(records)} trial records"
          + (f"; not fetched: {', '.join(missing)}" if missing else ""))
    return 0


def cmd_build(args: argparse.Namespace) -> int:
    pool = json.loads((args.gold_dir / "candidates.json").read_text(encoding="utf-8"))
    curation = json.loads((args.gold_dir / "curation.json").read_text(encoding="utf-8"))
    try:
        written = build.build(curation, pool, args.tasks_dir, args.gold_dir / "gold.json")
    except build.CurationError as exc:
        print(f"curation.json breaks the rules: {exc}", file=sys.stderr)
        return 1
    print(f"{len(written)} task files in {args.tasks_dir}; gold file {args.gold_dir / 'gold.json'}")
    return 0


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("step", choices=["candidates", "build"])
    parser.add_argument("--cache", type=Path, default=repodb.CACHE, help="where the repoDB file is kept (outside the repo)")
    parser.add_argument("--gold-dir", type=Path, default=ROOT / "gold" / "repodb-dev")
    parser.add_argument("--tasks-dir", type=Path, default=ROOT / "tasks" / "repodb-dev")
    args = parser.parse_args(argv)
    return {"candidates": cmd_candidates, "build": cmd_build}[args.step](args)


if __name__ == "__main__":
    sys.exit(main())
````

규칙 (설계 4.5):
1. 적응증은 `candidates.json`의 순서(`ind_id` 순서)대로 검토하고, 과제가 10개가 되면 멈춘다. 검토한 적응증은 과제가 되거나 `dropped`에 이유와 함께 남는다. 결과를 보고 고르지 않기 위한 규칙이다.
2. 실패한 약은 다음 세 조건을 모두 만족할 때만 인정한다. 두 출처(`repodb`, `ctgov`)에 같은 조건을 쓴다.
   1. 그 약이 그 임상의 시험 약이다. 병용 요법의 배경 약이 아니다.
   2. 그 질환 자체를 치료하려는 임상이다. 다른 증상, 합병증, 다른 질환(예: 암 환자의 우울증, 수술 통증)을 위한 임상이 아니다.
   3. 효능 부족(무익, 1차 평가변수 미달 포함)이나 안전성 때문에 멈췄다. 중단 사유에 `no safety concerns`, `not related to safety`처럼 부정이 있으면 인정하지 않는다. 기록을 받지 못한 NCT(`error`)는 다른 근거가 없으면 인정하지 않는다.
3. 인정한 실패한 약이 셋 이상이면 `repodb`에서 온 약을 먼저, 그다음 이름의 알파벳 순서로 둘을 고른다.
4. 승인된 약은 그 적응증의 `approved` 목록 가운데 그 질환 자체를 치료하는 약에서 고른다(보조 치료제와 진단약은 뺀다). 대안이 있으면 가장 널리 쓰이는 1차 치료제는 피하고, 남은 약 가운데 이름의 알파벳 순서로 첫 약을 고른다.
5. 같은 병을 가리키는 적응증(예: 비소세포폐암과 폐의 악성 종양)은 먼저 검토한 쪽만 과제로 만든다. 질문 하나로 묻기 어려운 넓은 적응증(예: 통증, 여러 장기의 편평세포암)은 이유를 적고 뺀다.

# Level-1 measurement of the repoDB dev set (gold design 7): generation 0 only, one task at a
# time, then the gold summary. A task that already has a finished run in OUT is skipped. A task
# whose run stopped halfway stops the script: resume that run first, then run the script again.
#
#   scripts/run_gold_dev.sh [OUT]      # default OUT: runs/gold-dev
set -euo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
OUT="${1:-$ROOT/runs/gold-dev}"
export PYTHONPATH="$ROOT/src"   # this checkout's code, not an installed copy
mkdir -p "$OUT"
for task in "$ROOT"/tasks/repodb-dev/*.json; do
  id="$(basename "$task" .json)"
  if compgen -G "$OUT/*-$id/result.json" > /dev/null; then
    echo "skip $id: already finished"
    continue
  fi
  if compgen -G "$OUT/*-$id/header.json" > /dev/null; then
    echo "stop: $id has a run in $OUT that did not finish; resume it with" \
         "'PYTHONPATH=$ROOT/src python -m reasonlineage resume <run folder>', then run this script again" >&2
    exit 1
  fi
  python -m reasonlineage run "$task" --generations 0 --seed 1 --out "$OUT"
done
python -m reasonlineage gold --gold "$ROOT/gold/repodb-dev/gold.json" "$OUT"/*/ --out "$OUT/report.json"
````

실행 폴더 이름은 `<YYYYmmdd-HHMMSS>-<과제 id>`다 (`cli._new_run_dir`). 그래서 `*-<id>/result.json`이 있으면 끝난 과제이고, `result.json` 없이 `header.json`만 있으면 멈춘 실행이다.
